# Upstream source and adaptation

Source: https://github.com/8bsite/app-landing-page-template
Commit: 1f89c0bb347e98f7eb7a3a0b7af08527d57580bd

This landing page adapts the 8B Linea template for Mootz. The original single-file layout, CSS system, GSAP/ScrollTrigger/Lenis scenes, section IDs, motion hooks, and accessibility fallbacks are retained. Product copy, brand color tokens, Mootz logos, and the phone concept preview are adapted. The page is static and does not connect to the Mootz app.

The original template license and third-party asset notices remain in LICENSE and CREDITS.md. The required Design: 8B footer attribution remains.

Local preview: serve this folder at http://localhost:1234 with a static file server.
